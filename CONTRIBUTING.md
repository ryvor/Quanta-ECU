First off, thank you for considering contributing to this project! 🚗⚡
This ECU project is built to be open for collaboration, learning, and experimentation, but comes with restrictions on personal/commercial use.

⸻

📌 Contribution Guidelines
	•	Fork and Pull Requests
	•	Fork the repository, create a feature branch, and submit a pull request.
	•	Keep changes focused and well-documented.
	•	Issues & Feature Requests
	•	Use GitHub Issues to report bugs, request features, or discuss ideas.
	•	Be as detailed as possible: include logs, hardware setup, and reproduction steps if applicable.
	•	Coding Standards
	•	Follow existing code style and structure.
	•	Comment where logic may not be obvious.

⸻

✅ Good First Steps
	•	Try the project on a bench setup and share feedback.
	•	Submit improvements to documentation.
	•	Report bugs with as much detail as possible.
	•	Suggest ideas for expanding the ECU feature set.
