# Quanta-ECU

An open, lightweight engine control unit built on the Raspberry Pi Pico. Designed to replace factory ECUs with a simple, modular system that starts as ignition-only and expands to full fuel + ignition management. Real-time control on the Pico, live tuning and charts via Raspberry Pi 3 web dashboard.

	•	Stage 1: Crank decoding + wasted-spark ignition.
	•	Stage 2: Add injector drivers + MAP/CLT/IAT inputs for full standalone.
	•	Stage 3: Web-based dashboard + live tuning via Raspberry Pi.

Built to be modular, reliable, and approachable for hobbyists who want to understand and control their engine management from the ground up.
